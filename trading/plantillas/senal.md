# Plantillas de señal y de análisis

## A) Formato de señal (lo que yo te envío y lo que tú aprenderás a escribir)

```
📊 [ACTIVO] | [TEMPORALIDAD] | [COMPRA / VENTA] ([Mercado / Buy Limit / Sell Limit / Buy Stop / Sell Stop])

🎯 Entrada:   
🛑 Stop Loss:          (     pips/puntos)
✅ TP1:                (R:B 1:   ) → 
✅ TP2:                (R:B 1:   ) → 
💰 Riesgo:       % → [tamaño] con [saldo]

🧭 Contexto (D1):    
🧱 Estructura (H4):  
🔫 Gatillo (H1):     
❌ Invalidación:     
📅 Noticias:         
⏳ Validez:          
```

## B) Plantilla para mandarme TU análisis (fase 2)

Copia, rellena y mándamela junto con las capturas de D1, H4 y H1.

```
ACTIVO:            
FECHA/HORA (UTC):  
PRECIO ACTUAL:     

1. CONTEXTO (D1)
   - Tendencia: alcista / bajista / rango
   - Por qué (giros, EMA 200): 
   - Zona mayor más cercana: 

2. ESTRUCTURA (H4)
   - Últimos giros (HH/HL o LH/LL): 
   - Fase actual: impulso / retroceso / rango
   - ¿BOS o CHoCH reciente?: 

3. ZONAS
   - Zona de interés: [desde] – [hasta]
   - Confluencias (mínimo 2): 
   - Liquidez cercana (máximos/mínimos iguales): 

4. ESCENARIOS
   - Principal (si… entonces…): 
   - Alternativo / invalidación: 

5. GATILLO
   - Qué tiene que pasar exactamente para entrar: 

6. NIVELES Y RIESGO
   - Entrada:       | Tipo de orden: 
   - Stop:          | Motivo: 
   - TP1:           | R:B: 
   - TP2:           | R:B: 
   - Saldo:         | Riesgo %:      | Tamaño: 
   - Noticias:      

7. CONFIANZA (1-5) y por qué: 
```

Te devolveré la puntuación (0-12) con la rúbrica del [Módulo 5](../05-como-analizar-una-captura.md#5-cuando-tú-me-mandes-tu-análisis-la-rúbrica).
